# Predicción de Abandono de Clientes (Churn)

**Autor:** Jose J. Carhuaricra Cusipuma - Curso Redes Neuronales y Deep Learning - UNI

Este repositorio contiene el código experimental desarrollado en **Google Colab** para la evaluación y comparativa de modelos predictivos de abandono de clientes (*Churn*), evaluando algoritmos basados en *Gradient Boosting* (**CatBoost**, **XGBoost**), ensambles tradicionales (**Random Forest**) y modelos fundacionales de aprendizaje en contexto (**TabPFN**).

---

## 🛠️ Entorno de Cómputo y Hardware
* **Plataforma:** Google Colab
* **Sistema Operativo:** Linux (Kernel 6.6.122+)
* **Procesador (CPU):** x86_64 (2 vCPUs asignadas)
* **Memoria RAM:** 12.67 GB
* **Aceleración:** Procesamiento íntegro en CPU

---

## 🚀 Instrucciones de Ejecución

Para ejecutar y reproducir el código de esta investigación, siga estos pasos:

1. Haga clic en el archivo **`Fuga_de_clientes.ipynb`** ubicado dentro de este repositorio.
2. En la parte superior del cuaderno, haga clic en el botón azul **`Open in Colab`**.
3. Una vez abierto en Google Colab, vaya al menú superior y seleccione:
   > **Entorno de ejecución** ➔ **Ejecutar todas** (o presione `Ctrl + F9`).
4. El cuaderno instalará automáticamente las dependencias necesarias (`tabpfn`, `catboost`, `xgboost`, etc.) y ejecutará la secuencia de entrenamiento, evaluación y generación de métricas.
